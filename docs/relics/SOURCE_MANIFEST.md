# Recoil Crew — Relic Chest Source Manifest

This pack contains only the source/reference files needed to derive the articulated relic chest.

## Included

- Closed and Open `.blend` sources
- Closed and Open `.fbx` exports
- Closed and Open `.obj` + `.mtl` exports
- Original Closed/Open icon renders for visual-fidelity comparison
- Original pack CC0 license
- Empty runtime/evidence destinations with instructions

## Explicitly excluded

All `Chest_Ingots` and `Gold_Ingots` assets are intentionally excluded.

## Material dependency note

The supplied chest MTL files contain three color/material definitions (`DarkMetal`, `Metal`, `Wood`) and do not reference external texture maps, so no additional texture files are required for these OBJ sources.

## Intended repository destinations

```text
docs/relics/source/ultimate-rpg-items/
public/assets/models/items/relic-chest/relic-chest.glb   # generated by Codex
docs/relics/evidence/
```
