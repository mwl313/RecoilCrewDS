# Recoil Crew — 업그레이드 시스템 설계

> **작성:** 2026-08-03 · **갱신:** 2026-08-04 (룰렛 구조 초안 — 카테고리 × 레어도 × 수치 레인지)
> **상태:** 초안 (수치 레인지는 조정 가능)
> **전제:** 게임잼 평가용 버전 — 직관성 최우선. 처음 하는 사람도 1분 안에 이해 가능해야 한다.
> **DDD:** Dopamine Driven Development 리서치(`Research/dopamine-research.md`) 기반

## 1. 개요 — 플레이어가 강해지는 레이어 2개

```
[몬스터 킬] → [경험치 드랍] → [레벨업] → ★ 레벨업 룰렛 (스탯 강화)
                                    ↘ [보물상자] → ★ 유물 룰렛 (초능력 부과효과)
```

- **레이어 1: 레벨업 룰렛** — 스탯을 직접 강화 (카테고리 × 레어도 × 수치)
- **레이어 2: 유물 룰렛** — 스탯과 겹치지 않는 초능력 같은 부과효과

설명에 필요한 단어: **"몬스터 죽이기 → 경험치 → 레벨업 → 룰렛" / "보물상자 → 유물"** — 시스템 2개, 드랍 1종.

### 1.1 보상 이벤트 계약 (2026-08-04 — 테크니컬 문서 §2.5 정합)

스폰/호드 시스템은 아래 보상 이벤트만 노출하고, 본 시스템은 이를 소비한다:

```
일반 몬스터 처치   → XP/드랍 기여 (앰비언트·웨이브 일반 킬)
웨이브 리더(엘리트) 처치 → 집중 보상 이벤트 (웨이브 클리어)
보스 처치          → 클리어 보상/스탯 이벤트
웨이브 코호트 퍼지 → XP/드랍/킬 트리거 없음 (리더 사망 시 소속 잡졸 전멸분)
```

- 퍼지 보상 없음은 경험치 드랍 테이블(§2)과 정합 — "잡졸은 최소 드랍" 원칙 유지

## 2. 드랍 & 경험치 & 레벨업

- **드랍 단일화:** 몬스터가 드랍하는 아이템 **1종** = 경험치 = 업그레이드 요소 (세분화하지 않음)
- 모든 킬이 하나의 보상으로 수렴 — "모든 킬이 이중 보상" (Brotato 원리 단순화)
- **경험치 일정치 달성 → 레벨업** (팀 공유 — 탱크 1대라 경험치도 공유, 누가 줍든 팀 레벨)
- **경험치 획득 방식 (2026-08-04 확정):**
  - **수동 픽업** — 경험치 조각을 직접 주워야 함 (자동 흡수 아님)
  - **자석 반경** — 탱크 주변 자석 반경 내 조각은 자동 흡수. **자석 반경은 스탯 변수** (업그레이드/유물로 확장 가능 — MAGNET CORE)
  - **근접 가속** — 경험치 조각이 탱크에 가까워질수록 이동 속도가 가속됨 (흡수 지연감 제거)
- **레벨업 = 업그레이드 룰렛 1회** (자동 트리거)
- 레벨업 빈도: 3분 스테이지당 **5~8회** 목표 (평균 25~35초 주기 — 보상 주기 압축 원리)

### 경험치 (초안)

```
잡졸 1xp · 웨이브 잡졸 2xp · 엘리트 40xp · 보스 150xp
레벨업 요구: 20 → 45 → 75 → 110 → 150 → 195 → 245 → 300
(3분에 레벨업 5~8회 목표 — 미정, 플레이테스트로 조정)
```

## 3. 레벨업 룰렛 (레이어 1 — 스탯 강화)

### 3.1 룰렛 구조 (2026-08-04 확정 — 메가봉크식 3선택)

```
룰렛 1회 = 카드 3장 제시 (각자 3선택 중 1개 선택) — 메가봉크 방식
카드 3장의 레어도 = 각각 독립 시행 (C 50% / R 30% / E 15% / L 5%)
레벨업 1회 = 2인 모드: 탱크 1 + 거너 1 = 룰렛 2회 (각자 3선택)
          = 싱글 모드: 룰렛 1회 (드라이버+거너 통합 풀) — 대신 레벨업 2배 속도
```

**레어도 4단계 (2026-08-04 레전더리 추가):** Common / Rare / Epic / **Legendary**
- 확률: **C 50% / R 30% / E 15% / L 5%** (기존 C60/R30/E10 → L 추가로 재정렬)
- 카드 3장 각각 독립 시행 — 같은 레어도 3장도 가능, 전부 Common도 가능 (첫 레벨업 하드코딩만 예외 — §5)
- **첫 레벨업 하드코딩** (첫 카드 Epic 확정 등 — §5 참조)

**룰렛 연출 (2026-08-04 확정 — 카지노 스타일):**
- **화면 일시정지** → 화면 중앙 오버레이 표시
- **카드 3장이 수직으로 카지노 룰렛처럼 회전** — 점점 느려지다 멈춤. 화려하고 두근거리는 연출 (사운드/파티클/빛)
- **유저 클릭 시 즉시 멈춤 (스냅)** — 대기 강요 없음
- ⚠️ **결과는 이미 결정됨 — 룰렛은 연출일 뿐** (실제 카드는 서버가 미리 결정 → 클라는 연출만 재생). 결정적 동기화 필요
- **타임아웃 10초** — 미선택 시 **랜덤 카드 1장 자동 픽**
- **멀티: 팀원 픽 마커** — 상대가 선택 완료했는지 오버레이에 표시 ("READY" / 대기) — **양쪽 모두 선택해야 게임 재개**

**카드 풀 구성 (2026-08-04 확정 — 싱글/멀티 차이):**
- **싱글 모드:** 카드 3장 모두 **통합 풀** (드라이버+거너) — 탱크 카드 3장이 나올 수도 있음
- **멀티 모드:** 드라이버 룰렛 = **탱크 카드만**, 거너 룰렛 = **거너 카드만** (역할 풀 분리)
- 카드 3장 고정 · 아이콘 + 이름 + 한 줄 효과 + 레어리티 테두리 · 역할 태그(DRIVER/GUNNER)

**룰렛 구성:**
- **카테고리:** 고정된 강화 축 (탱크 10종 + 거너 8종 — §3.3)
- **레어도:** 수치 레인지의 크기에 대응 — Legendary일수록 수치가 큼
- **수치:** 레어도별 **레인지(정수 %)** 에서 랜덤 — 매번 결과가 미세하게 다름 (변동비율 강화)

### 3.2 테이블 규칙

- **중복 획득 허용 — 곱연산 스택** (확정): 같은 카테고리를 다시 얻으면 `multiply`로 누적 (×1.15 → ×1.15² = ×1.32...). statResolver가 이미 지원 (`base + Σ(add) × Π(multiply)` + min/max 클램프)
- 효과는 스탯 정의 시 **`operation: 'multiply'`** 사용 (add는 합연산이라 곱이 안 됨)
- **무제한 스택** — "말도 안 되게 강해지는" 파워 판타지 (RoR2 스택 원리)
- **레인지 겹침 금지** — C/R/E 레인지가 서로 겹치지 않게 (레어도 의미 보존)
- **첫 레벨업 하드코딩** (§5 참조 — 첫 카드 Epic 확정)
- ⚠️ **머신건 재장전류 제외** — MG는 기본무기라 언제나 발사 가능. mgRate(발사속도) 업그레이드 없음

**수치 설계 원칙 (Legendary 추가):**
- 각 카테고리의 L 레인지는 E 상한을 넘지 않게 **단계 간격을 유지** (겹침 금지 원칙 유지)
- L 배율 ≈ E의 1.5배 상한 기준 (예: 이동속도 E +28% → L +42%) — "이 카드 한 장이 게임을 뒤집는" 체감
- Legendary 카드 = 금색 프레임 + 전용 사운드 + 화면 플래시 (카지노 룰렛 연출과 결합)

**설계 노트:**
- "재미 카테고리"(대포/점프/대시/공중/포탄 넉백/대시 데미지)는 레인지 폭이 커서 고레어도에서 자연히 잘 나옴 — 명시적 가중치 없이 빌드 지향 발생
- "안전 카테고리"(장갑/MG 정밀도)는 완만 — 초반 안정 옵션
- 조작감 문서(04)와 정합: 대시/점프/공중/반동 스탯이 업그레이드 대상과 일치
- **대시 데미지** (2026-08-04): 래밍(몸통 박치기) 데미지 제거에 따라 — **대시만이 탱크의 적 접촉 공격 수단**. 드라이버의 유일한 직접 공격 축
- **포탄 넉백** (2026-08-04): 포탄 폭발이 적을 밀어내는 힘 — 배럴 체인/절벽 콤보 유도, 공간 제어의 재미 축
- **제거됨 (2026-08-04):** 반동 관리(`tank.recoilImpulse`) — 반동은 "자원"이므로 억제 업그레이드 배제 · 포탑 회전(`weapon.turretTurnRate`) — 조준은 실력 영역

## 4. 유물 시스템 (레이어 2 — 초능력 부과효과)

- **보물상자**를 열면 **유물 룰렛 1회** → 유물 테이블에서 유물 1개
- 유물 = 레벨업 업그레이드와 **겹치지 않는 부과효과** (초능력 성격 — 트리거 기반: onKill/onHit/onTimer 등, `TriggeredEffectRegistry` 활용)
- **보물상자 획득 경로 2가지:**
  1. **맵 랜덤 배치** — 맵 곳곳에 뿌려둠 → **탐험 유도**
  2. **적 킬 시 낮은 확률 드랍** → **킬 유도**
- **웨이브 클리어(엘리트 처치) = 보물상자 확정 드랍** → 코어루프("웨이브 = 기회")와 연결
- 유물 레어도 **4단계** (Common/Rare/Epic/Legendary)
- 유물 **중복 획득 허용** — 합연산 스택 (유물별 규칙, 05-유물-테이블.md §2)

### 4.1 테이블 규칙 (2026-08-04 v3 확정 — `05-유물-테이블.md`)

- **유물 테이블 28종 확정** (Common 7 / Rare 9 / Epic 7 / **Legendary 5**) — 별도 문서 `05-유물-테이블.md` 참조
- **v3 변경:** v1/v2(34종) 전면 폐기 — 트럭/JACKPOT/크루링크/스코어/구매통화 의존 유물 제거. 스택 규칙 재설계 (합연산 통일 + 중복 불가 태그)
- 상자 롤 확률: C 55% / R 30% / E 13% / L 2% (트럭 E/L 보장 **없음** — 트럭 제외 확정)
- **시너지 시스템 없음** (리매치 모디파이어/팀 시너지 — 게임에서 제외 확정)

## 5. 첫 경험 하드코딩 (기대치 앵커링) — 2026-08-04 재정의

**첫 레벨업 (하드코딩 — "첫 카드 Epic 확정"):**
- 첫 레벨업의 **첫 번째 카드 = Epic 확정** (카테고리는 랜덤)
- **두 번째 카드 = 랜덤** (기획 확률)
- **세 번째 카드 = 50% 확률로 Legendary** (하드코딩)
- 이후 레벨업부터는 전부 기획 확률 (C50/R30/E15/L5)

**첫 보물상자 (하드코딩):**
- **첫 보물상자 = Epic 이상만 출현** (E 70% / L 30% — 또는 E/L 풀에서 균등)
- 이후 상자부터는 기획 확률 (C55/R30/E13/L2)

→ 목적: 첫 경험의 강도가 기대치의 기준 (VS 1-1-3-1-5 원리). "첫 레벨업에 Epic + Legendary 가능성" = 첫 1분 안에 도파민 피크
