## 0. TL;DR

- **유물 = 레이어 2 초능력 부과효과.** 레벨업(스탯)과 겹치지 않는 트리거/조건부 효과.
- **총 28종** (Common 7 / Rare 9 / Epic 7 / **Legendary 5**)
- **획득:** 보물상자만 (맵 배치 / 적 킬 드랍 / **웨이브 클리어 = 확정**)
- **스택 규칙:** % 수치는 합연산 통일 · 능력 부여형은 첫 획득 시 발동 + 수치 합연산 · 고유 능력은 🚫 중복 불가

## 1. 유물이란

```
[몬스터 킬] → [경험치] → [레벨업] → ★ 레벨업 룰렛 (레이어 1 — 스탯 강화)
                                    ↘ [보물상자] → ★ 유물 (레이어 2 — 초능력 부과효과)
```

| 항목 | 규칙 |
|------|------|
| 획득 경로 | ① 맵 랜덤 배치 ② 적 킬 시 확률 드랍 ③ **웨이브 클리어 = 확정 상자** (구매 통화 없음 — 유물이 상자의 유일한 보상) |
| 레어도 | Common / Rare / Epic / Legendary 4단계 |
| 상자 롤 확률 | C 55% / R 30% / E 13% / L 2% |
| 중복 | **획득 가능** — 합연산 스택 (유물별 정의, 아래 규칙) |
| 중복 불가 재등장 | +250 경험치 보상으로 대체 |
| 적용 | 즉시 적용 (룰렛 정지 화면에서) |

## 2. 스택 규칙 (v3 재설계 — 전면 적용)

| 유형 | 적용 방식 | 예시 |
|------|-----------|------|
| **합연산 %** | 중복 시 수치 그대로 합산 | MAGNET CORE ×2 = 자석 반경 +100% |
| **합연산 정수** | 중복 시 정수 그대로 합산 | DOUBLE JUMP ×2 = 점프 3회 · HEARTY TANK ×2 = 최대 체력 +40 |
| **능력+수치** | 능력은 첫 획득 시 1회 발동, 수치는 % 합연산 | UNSTOPPABLE ×2 = 대시 쿨다운 0 + 대시 데미지 +100% |
| **🚫 중복 불가** | 고유 능력 — 재등장 시 +250 경험치 | PHASE DASH · PHOENIX CORE · TWIN SHELL |

- **곱연산 금지:** 모든 배율은 % 플러스/마이너스 합연산으로 통일 (1.5배×1.5배 → +50%+50%) — 구현 단순화 + 스택 예측 용이
- **클램프:** 감소 % 스택은 0% 또는 최소값에서 클램프 (예: FRIENDLY SHIELD ×2 = -100% → 자해 0)

## 4. 설계 노트

1. **레벨업(순수 스탯)과 중복 0건** — 전부 조건부/트리거/능력 부여형 (v3 감사 확인)
2. **대시 공격 축** (래밍 데미지 제거 반영): ROADKILL·DASH REFUND·PHASE DASH·UNSTOPPABLE·BULLET TIME — "대시로 때리고, 대시로 피하고, 대시로 버티는" 드라이버 공격 판타지
3. **넉백 축** (포탄 넉백 신규 반영): HE PAYLOAD·GROUND POUND — 공간 제어
4. **경험치=유일 자원** 구조와 정합: MAGNET CORE·XP SURGE·NEWTON'S REVENGE(v3 제거) 대신 조건부 강화로 정합
5. **생존 축:** HEARTY TANK·FRIENDLY SHIELD·VAMPIRE ROUNDS·IRON WILL·PHOENIX CORE·SAFE HAVEN — 게임오버(재시작 없음)의 좌절 완화
6. **레전더리 5종은 "이 유물 하나가 곧 빌드"** — L 2% 희소성으로 기대치 앵커링.
   (폐기됨: "첫 웨이브 Rare 확정" — 확정 규칙은 **매치에서 처음 여는 보물상자는
   Epic 70% / Legendary 30%**이며, 이후 상자는 C55/R30/E13/L2.)

## 5. Audit (Aria — Fairness & Fantasy)

- **Fairness:** 🟢 웨이브 클리어 = 확정 상자 → "유물 못 얻어서 짐" 귀인 차단. 감소 %는 클램프로 역효과 차단
- **Fantasy:** 🟢 "반동을 타고 날아다니는 탱크" + "대시로 때리는 탱크" — v3는 두 판타지를 조건부 강화로 지지
- **리스크:** UNSTOPPABLE+PHOENIX CORE 동시 보유 = 생존+공격 극단 → PHOENIX CORE 1회 한정 + 중복 불가로 허용 범위
