# Monster System Content Report

Branch `monster-system`; generated by `scripts/generate-monster-roster.ts`
(re-runnable, single source table) and validated through the content pack.

## Roster

- 45 general monster definitions in `content/enemies/enemy.quaternius.*.json`:
  - 39 ordinary (fodder/specialist): 21 melee (contact-DPS), 18 ranged
    (one slow projectile each)
  - 4 elites: `alien-high-detail`, `cactoro-high-detail`, `fish-high-detail`,
    `ninja-high-detail` (tier scale 3, elite reward class)
  - 2 bosses: `demon-high-detail`, `yeti-high-detail` (tier scale 5, boss
    reward class, mixed ordered-cycle patterns, fixed damage)
- Production roster `enemyArtRoster.quaternius.mainStage`: 15 common families,
  4 elite heroes, 2 boss heroes, and complete stage-selective preload ids.
  The integration-preview roster is preserved.

## Curves, XP, engagement

- `enemyLevelCurve.mainStage`: 15 s interval, Lv1–13, ×1.20 HP, ×1.18 damage,
  boss phase Lv13.
- `enemyXpRewards.mainStage`: ambient 1+1/Lv, wave 2+2/Lv, elite 40+8/Lv,
  boss 150+0/Lv; Single Player ×2 via the existing `progressionMode.singlePlayer`
  policy (identical enemy difficulty across modes).
- `meleeEngagement.default`: spacing 1.25, slots 3–6, grace 0.35 s, release
  multiplier 1.35.

## Projectiles

7 validated `kind: 'enemy'` projectiles (5–12 m/s, positive life/radius,
zero gravity): Wizard Shot, Bone Shot, Ghost Bolt, Spit Shot, Ice Shot, Demon
Fireball, Yeti Ice Bolt. Ordinary ranged attacks fire exactly one.

## Authoring note

The design's canonical ordinary-roster stat table
(`08-몬스터-레벨링-성장곡선.md` / `09-몬스터-카테고리.md`) is not present in
the repository. The 39 ordinary stat sets follow the design's archetype rules
(anchored by the ninja/wizard examples and demon/yeti boss tables) and live
as one table in the generator script for easy replacement with canonical
values.
